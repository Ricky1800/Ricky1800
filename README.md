### Hi, I'm Ritvik 👋

I build websites and tools for local businesses in New Jersey through my studio, [OrbitBoyzz](https://orbitboyzz.me). The projects below grew out of that work: things small businesses and the freelancers who help them actually need, released as free open source.

#### Open-source tools

| Project | What it does | Stack |
| --- | --- | --- |
| [localbiz-site](https://github.com/Ricky1800/localbiz-site) | One config file → a fast, SEO-ready local business website, with 8 design themes and a live design panel. [Live demo](https://localbiz-site-demo.vercel.app) | TypeScript · Next.js |
| [local-seo-audit](https://github.com/Ricky1800/local-seo-audit) | Audits a business website for local SEO: Core Web Vitals, full-site crawl, competitor comparison, and a prioritized content plan | Python |
| [sitewatch](https://github.com/Ricky1800/sitewatch) | Single-binary uptime and SSL monitor with Discord/Slack/email alerts and a status page | Go |
| [ledgerlite](https://github.com/Ricky1800/ledgerlite) | Private, offline bookkeeping: bank CSV exports → categorized books and a P&L report | Rust |
| [leadbox](https://github.com/Ricky1800/leadbox) | 8 KB, zero-dependency "get a quote" widget for any website, with a free Google Sheets backend. [Live demo](https://ricky1800.github.io/leadbox/demo/) | JavaScript |

Issues labeled `good first issue` are open on every repo if you'd like to contribute.
